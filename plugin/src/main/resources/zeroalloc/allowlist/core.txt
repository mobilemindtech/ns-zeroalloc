# release mode (Interflow enabled). Verified against the 0.5.12 sources and
# the optimized LLVM IR; see docs/allowlist.md for the evidence and the
# methods that were deliberately left out.
#
# Exceptions thrown by these methods for invalid arguments (index out of
# bounds, division by zero) are accepted, like the ones of built-in array
# access and `/`.
