# Scala Native memory and unsigned operations.
#
# In NIR, Ptr, CArray, CStructN, Size and the unsigned types are heap
# classes. Inside a method, Interflow (release mode) inlines these
# operations and removes the boxes; a box is only allocated when a newly
# created value leaves the method (argument of a call that is not inlined,
# return value, field or array store). The plugin checks that boundary
# separately, so the methods below are accepted and their arguments do not
# count as escaping. In debug mode these operations DO allocate.
